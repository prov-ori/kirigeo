# Летопись — литература для гимназии

Интерактивная платформа по программе литературы для экстерна (гимназия, Эстония): 5 курсов, 50 уроков, 390 вопросов, 202 вопроса итоговых тестов преподавателя с образцами ответов, 384 карточки с интервальным повторением, лента времени, литературная Эстония.

Сайт: https://prov-ori.github.io/kirigeo/kirjandus/

## Структура
Все файлы лежат в корне — так репозиторий можно загрузить через веб-интерфейс GitHub даже с телефона.

| Файл | Что внутри |
|---|---|
| `index.html` | оболочка, мета-теги и превью для соцсетей |
| `engine.js` | универсальный движок (роутер, уроки, квизы, карточки, игры, поиск, достижения) |
| `config.js` | название, курсы, цвета, звания |
| `c1.js` … `c5.js` | уроки курсов I–V |
| `extra.js` | словарь, произведения, герои, писатели, места Эстонии |
| `tests.js` | тесты преподавателя с образцами ответов |
| `og-image.png` | превью 1200×630 для ссылок |
| `sw.js` | офлайн-режим: сайт работает без интернета после первого открытия |

## Публикация на GitHub Pages
1. Создайте репозиторий `kirjandus` и загрузите все файлы в корень ветки `main`.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу выше.

Если имя пользователя GitHub не `prov-ori`, замените адрес в `index.html` (canonical, og:url, og:image, twitter:image, vk:image) — иначе превью в соцсетях не появится.

## Проверка превью

- Facebook: https://developers.facebook.com/tools/debug/
