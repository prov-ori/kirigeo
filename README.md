# КириГео — литература и география для гимназии

Одна платформа, два предмета. Статический сайт без сборки и серверной части.

Сайт: https://prov-ori.github.io/kirigeo/

| Раздел | Адрес | Что внутри |
|---|---|---|
| Портал | `/` | выбор предмета, общий прогресс (читает те же данные localStorage, что и приложения) |
| «Летопись» — литература | `/kirjandus/` | 5 курсов, 50 уроков, 390 вопросов, 202 вопроса тестов преподавателя, ленты времени, литературная Эстония |
| GEO — география | `/geo/` | 3 курса, 42 урока, атлас, 5 лабораторий, 9 исследований, интерфейс RU/ET |

Цифры на портале считает `scripts/gen-stats.mjs` из реального содержимого (файл `stats.js`). После правки уроков выполните:

```sh
node scripts/gen-stats.mjs
```

## Структура
- `index.html`, `hub.css`, `hub.js`, `stats.js` — портал.
- `kirjandus/` — бывший репозиторий `prov-ori/kirjandus` (см. его `README.md`).
- `geo/` — бывший репозиторий `prov-ori/geo` (запуск: `cd geo && npm run dev`, тесты: `npm test`). GEO работает прямо из исходников, `npm run build` нужен только для Vercel.
- `scripts/check.mjs` — проверка локальных ссылок в html.

Аккаунты и синхронизация между устройствами: `docs/ACCOUNTS.md`.

Прогресс каждого предмета хранится отдельно (`kirjandus.v1`, `geo-expedition-v1`); экспорт/импорт JSON — в разделе «Прогресс» предмета.

## Публикация (GitHub Pages)
Settings → Pages → Deploy from a branch → `main` / `(root)`. Все пути относительные, поэтому сайт работает из подпапки `/kirigeo/`.
